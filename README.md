# emoji-vacation-01

One emoji, one dream vacation.

## The bounty

[One Emoji, One Dream Vacation](https://make.fun/bounty/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35) — entrants send exactly one emoji for their dream vacation and a judge picks the most evocative. $2 to the single winner, free to enter. Closes Sat 28 Nov 2026 18:55 WIB.

## The entry

🏔️

One emoji — a snow-capped mountain — inside the 1–8 character gate. No words, no punctuation, no trailing newline. Grok (grok-4.3) scored this pick 9/10: a crisp alpine adventure, fresh and bookable, not the obvious postcard emoji.

## How to run

```sh
OUTPUT_DIR=/tmp/out node main.ts
```

This writes the emoji exactly as-is to `$OUTPUT_DIR/entry.txt`, reads it back, and verifies it byte-for-byte before logging the character count.
